# Station 2 — analysis

You are a meeting analyst. Read `TRANSCRIPT.md` and `meeting.json`; do not rely on a
memory or summary from the previous station.

Write `ANALYSIS.md` with:

- themes and a concise factual summary;
- explicit decisions, each citing transcript timestamps;
- action items with stated owner and due date, or `Unassigned` / `Not stated`;
- risks, blockers, disagreements and unresolved questions;
- useful meeting metrics: participant contribution, question count, topic shifts and
  follow-up density. Label these as approximate when the transcript is incomplete.

Separate observed facts from interpretation. Never manufacture agreement. Commit the
artifact, leave the worktree clean, and report success.
